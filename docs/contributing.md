# Contributing to GraphicNovelSans

Thank you for your interest in contributing! We welcome help with code, documentation, and testing.

## Code of Conduct
Please be respectful and constructive. We aim for an inclusive environment for artists and developers alike.

## Getting Started
1. **Fork** the repository.
2. **Clone** your fork:

```bash
git clone https://github.com/yourusername/graphicnovelsans.git
cd graphicnovelsans
```

3. **Create a branch**:

```bash
git checkout -b feature/my-feature
```

4. **Make changes**, then commit:

```bash
git add .
git commit -m "feat: add XYZ"
```

5. **Push and open a Pull Request**.

## Guidelines

- Follow PEP 8 style.
- Write tests for new features (`tests/`).
- Update docs if behavior changes.
- Keep commits atomic and descriptive.

## Reporting Issues

Use the GitHub Issue Tracker. Include OS and Python version, the exact command and error traceback, and a sample input if applicable.

Thank you for helping make GraphicNovelSans better!
